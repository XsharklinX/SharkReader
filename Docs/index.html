Preguntas frecuentes

¿Tienes dudas?

Las respuestas a las preguntas más comunes sobre SharkReader.

¿SharkReader es completamente gratuito? +
Sí, SharkReader es gratis y siempre lo será. No hay plan de pago, suscripción ni funciones de pago. Todo lo que ves en la app está disponible para todos sin coste.
¿Mis libros y datos están seguros? ¿Se suben a algún servidor? +
Completamente seguros. SharkReader es local-first: todos tus libros, anotaciones, estadísticas y configuración se guardan únicamente en tu dispositivo (en IndexedDB, un almacenamiento local del navegador integrado en Electron). Nunca se envía nada a ningún servidor externo. Ni tus libros, ni tus notas, ni tus datos de lectura.
¿Qué formatos de libro soporta? +
SharkReader soporta EPUB (con todas sus variantes: EPUB 2 y EPUB 3) y PDF. Los PDF tienen búsqueda de texto, TOC, highlights multicolor y dark mode. Los EPUB tienen subrayados, notas, tipografía personalizable por libro y todas las features avanzadas.
¿Puedo usar SharkReader sin internet? +
Sí, perfectamente. SharkReader funciona completamente sin conexión a internet. La única excepción es si usas funciones opcionales como el fetch de portadas desde OpenLibrary o la importación de fuentes OPDS externas, que sí requieren red puntualmente.
¿Qué es Sharky y para qué sirve? +
Sharky es la mascota de SharkReader: un tiburón pixelart que aparece en la esquina de la pantalla. Te felicita cuando terminas un libro, te avisa si estás a punto de perder tu racha de lectura, celebra tus hitos y reacciona a tus acciones. Puedes activarlo desde el Workshop de addons y desbloquear cosméticos (gafas, corona, bufanda, gorra) según tu nivel de XP.
¿Puedo importar mis libros de Goodreads? +
Sí. Desde la biblioteca, el botón "GR" en la barra superior acepta el CSV de exportación de Goodreads. Importa título, autor, rating, estado (leído/por leer), fechas y portadas automáticamente desde OpenLibrary usando el ISBN. El proceso detecta duplicados y no sobreescribe libros que ya tengas.
¿Funciona en macOS o Linux? +
Por ahora SharkReader solo tiene instalador oficial para Windows 10 y 11. Está construido con Electron, por lo que técnicamente podría compilarse para macOS o Linux, pero no hay builds oficiales para esas plataformas en este momento.
¿Cómo hago un backup de mis libros y progreso? +
Desde Configuración → Backup portable puedes exportar todos tus datos (libros, anotaciones, estadísticas, colecciones) en un archivo JSON. Para restaurarlos en otro PC, importa ese archivo desde la misma pantalla. SharkReader también tiene sync automático a carpeta local (OneDrive, Dropbox, etc.) que puedes activar en Configuración.
¿Por qué Windows me avisa de "aplicación no reconocida" al instalar? +
Es la alerta azul de Windows SmartScreen. Aparece porque SharkReader aún no tiene firma de código (un certificado de validación que cuesta ~200€/año). La app es completamente segura. Para instalarla, haz clic en "Más información" y luego en "Ejecutar de todas formas". El código fuente está disponible en GitHub para quien quiera verificarlo.
¿Cómo reporto un bug o sugiero una función? +
Abre un issue en GitHub → Issues. Incluye tu versión de SharkReader (visible en Configuración → Acerca de) y una descripción del problema. Para sugerencias, usa la etiqueta "enhancement".
